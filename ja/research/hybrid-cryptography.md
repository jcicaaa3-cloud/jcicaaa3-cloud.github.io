暗号化したファイルを送るたびにパスワードを別に伝えるのが面倒だったので、RSA公開鍵とAESを組み合わせるツールをPowerShellとC#で作っています。構成とテストすることのメモです。ログ、秘密鍵、パスワードは載せていません。

## 構成

ファイルはAESで暗号化し、そのAESの鍵を受信者のRSA公開鍵で暗号化します。受信側は秘密鍵でAESの鍵を戻してからファイルを復号します。

```text
送るファイル ── AES暗号化 ──────────── 暗号文
                  │
             ランダムなAES鍵
                  │
          受信者のRSA公開鍵
                  │
            暗号化された鍵

受信者：RSA秘密鍵でAES鍵を復元 → ファイルを復号
```

アルゴリズムはAES-256-GCMとRSA-OAEP（SHA-256）にしました。GCMのタグ検証に失敗したら結果は捨てます。

## チェックリスト

| 項目 | 確認すること |
| --- | --- |
| AES鍵 | ファイル（作業）ごとに新しく作るか |
| GCM nonce | 同じ鍵で再利用していないか |
| RSA | OAEPの設定が両側で同じか |
| 改ざん | ヘッダー、暗号文、タグが変わったら拒否するか |
| エラー・中断 | 不完全な平文が残らないか |
| 大きいファイル | メモリを使いすぎないか |

`.cpenc`、`.cprsa`という独自形式なので7-Zipでは開けず、受信者にも同じツールが必要です。
