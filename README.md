# jcicaaa3 Security Lab

개인 컴퓨터보안 연구 블로그의 GitHub Pages 저장소입니다.

- 사이트: https://jcicaaa3-cloud.github.io/
- 연구 글: `/research/`
- 분석 화면: `/evidence/`

## 파일 위치

| 위치 | 용도 |
| --- | --- |
| `index.md` | 첫 화면 |
| `research.md` | 검색 가능한 글 목록 |
| `evidence.md` | 직접 남긴 분석 화면 |
| `about.md` | 소개 |
| `_posts/` | 연구 글 |
| `_layouts/` | 페이지 틀 |
| `assets/main.scss` | 색과 글꼴, 레이아웃 |
| `assets/site.js` | 글 목록 검색과 필터 |
| `assets/images/` | 분석 중 남긴 화면 |

외부 폰트·광고 스크립트·분석 추적기는 사용하지 않습니다. 실행 가능한 악성코드 샘플 및 개인키는 저장소에 포함하지 않습니다.

## 자료 표기

게시글은 직접 확인한 캡처와 외부 보고서에서 읽은 내용을 구분해 적습니다.
공개 보고서, Microsoft API 문서, NIST·RFC 문서는 각 글의 하단에 출처를 표시합니다.
랜섬웨어 원본이나 암호화 키, 개인 로그는 게시하지 않습니다.
